# Security Policy

## Supported Versions

Currently, only the latest release of `HyperDrive AI` is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1.0 | ❌        |

## Reporting a Vulnerability

Security and privacy are top priorities for this project. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately by emailing me. We take all security vulnerabilities seriously and will work to resolve them rapidly.

### What to include in your report

* A descriptive summary of the vulnerability.
* Detailed steps to reproduce, including any relevant code or HTTP requests.
* Any additional information, such as the potential impact of the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you're interested, we'd also love to publicly acknowledge your contribution to keeping the project secure.
